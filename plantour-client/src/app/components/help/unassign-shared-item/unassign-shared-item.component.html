Unassign Shared Item

Note: Unassigning a shared item from a participant does not delete the shared item. It simply removes that person's responsibility. You can reassign it to other participants if needed.
Important: If a participant has already accepted the assignment and started preparing, make sure to communicate with them before unassigning the shared item.
