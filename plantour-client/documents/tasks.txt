Plantour — это приложение, предназначенное для путешественников, позволяющее планировать, организовывать, готовить, проводить, хранить и повторно использовать туры на разных устройствах, обеспечивая безопасное хранение данных и широкие возможности для групп путешественников. Админы могут создавать путешествия и приглашать в них Участников. Админ может быть Участником путешествия. Каждый Участник создает свой список Items. Каждый Item может быть упакован в Bag, а может быть без упаковки. Для создания списока Items могут использоваться Templates. Приложение поддерживает список Shared Items c назначением ответственного Участника. Назначения могут быть ждущими, выполненными, или пророченными. Путешествия могут быть Planned, Preparation, Active, Completed. Можно выгружать как PDF Bag Packing List и Trip Report. Можно обмениваться комментариями по путешествию.
