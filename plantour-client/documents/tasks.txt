Создай новый Angular 20 standalone компонент ListActionsComponent. Этот компонент будет служить для задания условий и выполнения фильтрации и/или сортировки входного массива произвольных объектов. Он должен возвращать потребителю через EventEmitter новый фильтрованный / сортированный массив с подсветкой вхождений строки, по которой выполнялась фильтрация. Используй PrimeNG и три файла: ts, html и scss.

Компонент получает как @Input два параметра

1) массив объектов для обработки data
[

    "age": "30",
    "status": "active"

    "status": "invited"
}
]
Это лишь пример, реальные данные могут быть какими угодно.

2) Объект - конфигурацию config. Все данные всегда заданы. Пример: 
{
    "property": "name",
    "label": "Name",
    "filter": "true",
    "sorting": "text",
    "lookup": "true",
    "lookupIcon": "person"
},{
    "property": "category",
    "label": "Category",
    "filter": "false",
    "sorting": "text",
    "lookup": "true",
    "lookupIcon": "category"
},{
    "property": "age",
    "label": "Age",
    "filter": "true",
    "sorting": "number",
    "lookup": "true",
    "lookupIcon": "age"
},{
    "property": "status",
    "label": "Status",
    "filter": "true",
    "sorting": "none",
    "lookup": "true",
    "lookupIcon": "status"
}


Компонент должен создать панель c тремя секциями, расположенными по горизонтали. Первая и третья секции фиксированной ширины. Вторая средняя секция занимает все доступное пространство по ширине.

В первой секции находится Select (используй PrimeNG Select, a не DropdownModule), содержащий items c иконками, соответствующими объектам в конфигурации. В выпадающем списке показаны не только иконки, но и labels. Сначала идут члены конфигурации у которых "lookup": "true". Затем item для членов конфигурации где "filter": "true". И в конце item для сортировки для членов конфигурации где "sorting" !== "none".

Для всех lookup items должен быть построен lookup-list из сортированных distinct значений, находящихся в property массива data.

Когда юзер выбирает lookup item в средней секции появляется Select, содержащий lookup-list, первый элемент списка выбирается автоматом. Входной список фильтруется по условию property == что выбрано из lookup-list. Case insensitive.

Когда юзер выбирает filter item в средней секции появляется Input, куда юзер может ввести строку фильтрации. Входной список фильтруется по условию найдено ли вхождение заданной юзером строки в членах массива по свойствам, укуазанным c filter = true в конфигурации. Case insensitive. Числа трактуются как строки. Вхождения строки в фильтрованном выходном списке должны быть подсвечены в UI, поэтому исзодные строки нужно заместить на HTML типа `${before}<mark>${match}</mark>${after}`

Когда юзер выбирает sorting item в средней секции появляются два select, один c label для выбора поля сортировки, второй для выбора  из "asc", "desc", "none". Во втором должны быть соответствующие иконки. При сортирвке нужно принимать в внимание тип свойства "string" или "number". Сортировка может выполняться только по одному свойству.
