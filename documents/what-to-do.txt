It is necessary to add users managing code to plantour-server and plantour-client. 

The API should return ApiErrorResponse including StatusCode, Code and Message.

There are two roles: Admin and Participant

If Admin is signing in
======================

- find their users record by email, if not found or wrong password return 
new ApiErrorResponse 
{
    StatusCode: 401,
    Message: Wrong email or password
    Code: NO_ACCESS
}

- check their access_type_id, if not "Active" or "Pending" return 
new ApiErrorResponse 
{
    StatusCode: 403,
    Message: The account suspended (or banned or archived)
    Code: NO_ACCESS
}


- if Active - give access, return 
new ApiErrorResponse 
{
    StatusCode: 200,
    Message: Welcome back to Plantour
    Code: ACCESS_OK
}

- if Pending - check if a record in user_email_confirmations exists
    
    - if no record - send an email asking for email confirmation, return 
    new ApiErrorResponse 
    {
        StatusCode: 403,
        Message: Please go to the email we sent to you and click on the link to confirm your email address,
        Code: NO_ACCESS
    }

    - if record exists - check confirmed_at. 
        -if it is null - return
        new ApiErrorResponse 
        {
            StatusCode: 403,
            Message: Please go to the email we sent to you and click on the link to confirm your email address,
            Code: NO_ACCESS
        }
        -if it has a value - return
        new ApiErrorResponse 
        {
            StatusCode: 200,
            Message: Welcome to Plantour,
            Code: ACCESS_OK
        }
        and update users.access_type_id from Pending to Active


If Participant is signing in
============================

Paricipants send access_code tying them to the Admin user. 

    - if their access_code ok
        - check their access_type_id in users, if not "Active" return 
        new ApiErrorResponse 
        {
            StatusCode: 403,
            Message: The account suspended (or banned or archived or pending)
            Code: NO_ACCESS
        }
        - if active return
        new ApiErrorResponse 
        {
            StatusCode: 200,
            Message: Welcome back to Plantour,
            Code: ACCESS_OK
        }

    - if their access_code is not ok - return
        new ApiErrorResponse 
        {
            StatusCode: 401,
            Message: You have no access to Plantour. Please ask your Administartor to re-send the invitation email to you,
            Code: NO_ACCESS
        }

If Admin token and refresh_token expired or wrong - Just Ask them to sign in

If Participant token and refresh_token expired or wrong - Offer them to ask their admin to re-issue invitation emdil
